# South Africa Energy Transition Dashboard

Interactive academic dashboard tracking South Africa's progress toward **SDG 7: Affordable and Clean Energy**.

## Main dashboard
Open `index.html` (GitHub Pages root).

Sections: Overview, Energy System, Access, Renewables, Efficiency, Transition, Sources.

## Data
- Tracking SDG 7 / Energy Progress Report 2026 datasets: indicators 7.1.1, 7.1.2, 7.2.1, 7.3.1, 7.a.1 and 7.b.1.
- Statistics South Africa: 2024 electricity generation mix.

Latest years differ by indicator because official reporting lags differ.

## Previous Sweden dashboard
The original project is preserved as `sweden.html` with its existing `script.js`, `style.css`, and data files.

## Tech
HTML, CSS, JavaScript, Chart.js.


## Country switcher
The site includes both dashboards under one GitHub Pages project. `index.html` opens South Africa and the country switcher links to `sweden.html`; the Sweden page links back to South Africa.
